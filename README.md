# 🤖 Tata Capital Support Assistant

### AI-Powered Customer Support, Human Agent & Intelligent Conversation Management Platform

A full-stack customer support platform developed using **PHP, CodeIgniter 4, MySQL, JavaScript, REST APIs, WebSocket and Ollama-based Local LLM integration**.

The platform combines an **AI-powered chatbot**, **Human Agent Support**, **Multi-Customer Communication**, **Ollama-powered conversation management** and a centralized **Admin Dashboard**.

Customers can interact with the AI chatbot for common queries and can also switch to a human agent whenever manual assistance is required.

# 📌 Project Overview

The Tata Capital Support Assistant is designed as a complete customer-support platform that combines automated AI assistance with human-agent communication.

The platform provides:

- 🤖 AI Chatbot
- 🧠 Ollama Local LLM

- 👥 Multiple Customer Support
- 💬 Manual Human-Agent Chat

- 📋 Complaint Management
- 📜 Conversation History

- 📊 Admin Dashboard
- 🔌 REST API Integration
- ⚡ Real-Time Communication

# 🎯 Project Objectives

The main objectives of the platform are:

- Provide 24/7 automated customer support
- Reduce repetitive customer-support queries
- Provide guided chatbot workflows
- Allow customers to directly communicate with human agents
- Allow agents to handle multiple customers simultaneously
- Maintain separate conversations for different customers
- Use Ollama for AI-powered conversation processing
- Assist in managing manual customer conversations
- Maintain customer conversation history
- Provide complaint registration and management
- Provide centralized admin monitoring
- Integrate external APIs
- Build a scalable customer-support platform

# 🧠 Ollama AI Integration

The platform uses **Ollama** for local Large Language Model processing.

Ollama is integrated into the chatbot and conversation-management workflow.

The AI layer can process customer messages, understand conversation context and assist in managing customer interactions.
